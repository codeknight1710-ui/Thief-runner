# Thief Runner

A simple arcade game inspired by Flappy Bird, built with Python and Pygame.

## How to Play

Help the thief navigate through obstacles while avoiding the police!

- Press Space or the designated control to move.
- Avoid hitting the walls and obstacles.
- Try to survive as long as possible.

## Built With

- Python
- Pygame

## Running the Game

1. Install Python.
2. Install Pygame CE with `pip install pygame-ce`.
3. Download or clone this repository.
4. Run `python main.py` from the project folder.
